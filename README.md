# VideoSnathan

Plataforma de vídeos inspirada nas funcionalidades de grandes plataformas de vídeo, com identidade visual própria.

## Objetivo
Construir uma plataforma completa com:

- Página inicial e recomendações
- Busca de vídeos e canais
- Canais e inscrições
- Upload e reprodução de vídeos
- Curtidas, comentários e respostas
- Playlists e histórico
- Shorts/vídeos verticais
- Notificações
- Studio do criador
- Moderação e denúncias
- Autenticação
- Recursos de IA opcionais

## Estrutura inicial

`frontend/` — interface web

`backend/` — API e regras de negócio

`docs/` — arquitetura e roadmap

## Desenvolvimento

A implementação será feita por etapas, começando pelo frontend navegável e depois adicionando autenticação, banco de dados, upload/processamento de vídeo e recursos sociais.
